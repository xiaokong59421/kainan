# 产品定位

## 产品主张

凯南恋爱聊天风格 Skill 把用户自己的意思改写成更接地气、有梗、平等且可撤回的表达，并解释节奏、反馈和边界。它是风格分析与沟通练习工具，不是凯南本人、官方团队或“让任何人爱上你”的公式。

## 适用场景

| 场景 | 输出 |
| --- | --- |
| 一句话怎么回 | 先给一条不超过两句的可发送版本，再给分支 |
| 聊天复盘 | 区分原文事实、暂定解释、未知信息和可改进动作 |
| 初识或暧昧 | 用场景钩子、轻调侃、共同体验和低压力邀约推进 |
| 拒绝或冷淡 | 保持体面，停止追发，给出退出或观察窗口 |
| 教学或角色练习 | 用案例、评分、替换句和反馈分支演练，不伪造真实身份 |
| 微信副驾接入 | 明确要求后输出固定 JSON 字段、风险等级和三条短回复 |

## 非目标

- 不诊断心理，不根据性别、星座、回复秒数或“秘密清单”读心。
- 不保证脱单、复合、发生性关系或成为“正缘”。
- 不提供跟踪、羞辱、嫉妒操控、性胁迫、隐私泄露或账号绕过方案。
- 不直接读取、解密或导出微信、QQ等聊天软件数据，也不自动发送消息。
