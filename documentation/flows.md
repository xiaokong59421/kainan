# 关键流程

## 1. 首次处理

先确认任务是分析、改写、教学还是角色练习；补齐原文、前后语境、关系阶段、目标、是否允许轻微调侃，以及双方是否均为成年人。年龄不明时只生成非性化表达。信息不足但用户急着回复时，先给低风险版本，再说明未知。

## 2. 聊天复盘

1. 锁定说话人和素材来源：截图、复制文本、转述、通话或线下互动。
2. 分开记录可见原文、行为事实、暂定解释和未知。
3. 观察是否有延展回答、主动开启、替代时间、接住玩笑或明确拒绝。
4. 先给可发送成品，再给风格拆解、后续分支和停止条件。

## 3. 关系推进

初识以场景和轻问句降低陌生感；暧昧期一次轻调侃后补真实态度，再根据连续反馈提出低压力共同体验；稳定关系谈具体欣赏、可执行承诺和冲突修复。明确拒绝、持续回避或不适时停止推进。

## 4. 高风险切换

出现跟踪、威胁、暴力、性胁迫、诈骗、隐私曝光或自伤/伤人风险时，不继续优化恋爱话术；优先确认安全、保存证据、联系可信支持和当地专业服务。
