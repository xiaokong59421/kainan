# 知识库治理

## 分层

| 层级 | 目录 | 用途 |
| --- | --- | --- |
| 行为规则 | `SKILL.md` | 决定何时询问、怎样拆分证据、怎样输出和何时停止 |
| 风格知识 | `references/knowledge/` | 记录可观察风格、主题转译和来源限制 |
| 实用材料 | `references/practical/` | 提供场景化回复、教学节奏、JSON 契约和后续分支 |

## 证据等级

1. 用户明确提供的原文、逐字稿和上下文：可以观察表达，但不代表全部内容。
2. 可核验的一手公开页面：可以确认页面当次显示的标题、账号或简介。
3. 搜索摘要、百科二手条目和转载：只能作为主题线索，不能证明观点或效果。
4. 流行说法与经验策略：必须标注适用条件、未知和长期代价。

## 更新规则

- 新来源记录访问日期、URL、观察到的事实和无法核验的部分。
- 不把“女生都怎样”、固定等待时间或清单标题写成个体心理定律。
- 新话术保留适用阶段、积极/模糊/拒绝分支和停止条件。
- JSON 模式保持固定字段、可解析示例、三种不同策略和高危核实提醒；不要把 JSON 契约混入普通输出。
- 不将私密聊天、真实身份、学员案例或原始媒体沉淀到公开知识库。
- 修改文件后运行 `python3 scripts/validate_skill.py` 并检查相对链接。
