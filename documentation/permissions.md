# 权限边界

| 资源或动作 | 本 Skill 的处理 |
| --- | --- |
| 用户提供的文字或截图 | 只读取完成任务所需内容，建议遮盖身份和第三方隐私 |
| 平台公开页面 | 仅使用用户提供或可核验的公开元数据，记录访问限制 |
| 微信、QQ等聊天数据库 | 不读取、不解密、不导出、不绕过权限 |
| 外部账号和消息 | 不登录、不代发、不替用户操作 |
| 本地原始 DOCX | 用于用户自己的研究，不随仓库发布 |
| Skill仓库 | 公开文件可读；不应包含凭据、私密案例或未授权课程全文 |

最终是否发送、邀约、继续或退出由用户决定。建议必须保留对方的拒绝权和用户自己的退出权。
