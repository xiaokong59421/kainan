# 架构说明

## 组件

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| 行为入口 | `SKILL.md` | 定义触发范围、证据边界、输出顺序和安全切换 |
| 界面元数据 | `agents/openai.yaml` | 定义名称、简介和默认提示词 |
| 风格知识 | `references/knowledge/` | 保存风格画像、来源台账和主题转译 |
| 实用材料 | `references/practical/` | 保存可发送回复、教学和分支模式 |
| 校验器 | `scripts/validate_skill.py` | 检查结构、链接、预算、敏感文件和运行时边界 |
| 项目文档 | `documentation/` | 记录产品、流程、权限、变量和知识库治理 |

## 运行方式

代理先加载 `SKILL.md`，再按当前问题读取 1–3 份相关参考；不会批量加载全部资料。入口中的“框架、窗口、动能、骚”等词只作为可验证、可撤回的沟通假设，不能替代对方的明确意愿。

仓库没有服务器、数据库、定时任务、账号系统或外部 API 密钥。发布运行内容是 `SKILL.md`、`agents/`、`references/` 和 `assets/`（如存在）；原始 DOCX 与本地研究台账不属于运行时。

## 信任边界

1. 用户提供的聊天、转述和平台材料可能不完整或带有隐私。
2. Skill 指令和参考资料只能引导模型，不能替用户做现实决定。
3. 模型输出不会自动发送，也不会获得对方账号、位置或私密数据。
4. 平台搜索摘要、转载和营销文案不能升级为研究证据或官方归属。
